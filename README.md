# BoredInClass

Games to play when you probably shouldn't be.

## Games

- **Chopsticks** — 2-player online finger game ✅
- **Tic Tac Toe** — coming soon
- **Sudoku** — coming soon

## Setup

```bash
npm install
cp .env.example .env.local
# Add your Firebase config to .env.local
npm run dev
```

See [CLAUDE.md](./CLAUDE.md) for Firebase setup and deploy instructions.
